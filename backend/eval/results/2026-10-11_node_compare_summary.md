## 事前登録からの逸脱と補足（この節だけ手で書いた）

逸脱:

- 手順・指標の式・判定規則・閾値は変えていない。実行順は、S0 単独（LLM 0回、H5 を確認）→ 煙テスト（q01 で S1・M1・M2 を1回ずつ。LLM 16回。集計に使わずコミットもしない）→ 本実行（予算 384 = 400 − 16、使用 197）。LLM の使用は合計 213/400。429 / 503・タイムアウト・上限超過は0件だった。
- ハーネスのコミット（74817be）は事前登録（33ff759）の後、LLM 実行の前。
- 結果を見た後の変更は1件だけ: §5 で出すと決めていた集計値のうち表に無かったもの（検索系の LLM リクエスト中央値・ツール呼び出し・latency 平均と、副次指標の M1 の事前接続時間）を足した（6e16872）。式と判定は変えていない。

補足（判定の読み方に関わる観察。どれも1回ずつの実行から読んだもの）:

- unclear の合否は事前登録どおり cited_codes だけで決めている。q13（この授業難しい?）は M1・M2 とも「どの科目か」と聞き返したが、M1 は例として挙げた GMS-101・GMS-201 を cited_codes に入れて不合格、M2 は例の GMS-301 を本文にだけ書いて合格になった。q13 での M1 と M2 の差は、例示したコードを cited_codes に入れたかどうかの差で、振る舞いの差ではない。
- q12（金曜3限に空いてる授業は?）の M2 は、get_course_details で全20科目の開講時期を引き、金曜3限は GMS-205（秋学期）だけだと答えた。シードの開講時期と一致する正しい回答だが、golden は静的探索が時間割で絞り込めないことを前提に out_of_scope（候補を出さない）を正解にしているので不合格になる。M1 は「時間割の情報が登録されていない」と答えて合格した（Neo4j の Course には開講時期が無い）。golden の unclear は静的 DAG の守備範囲を表していて、RDB を引ける条件には合わない問いが混ざっている。
- q11（おすすめ）は M1・M2 とも、主観的な評価はしないと断ったうえで系統別に科目を並べた（cited は20件と16件）。q14（データサイエンスの次は?）は両方とも聞き返さずに GMS-301 を起点と決めて後続を答えた。
- precision の減点は、ほとんどが前提科目への言及による（例: q01 の GMS-202 は GMS-303 のもう1つの前提科目）。q10（メディア情報論に似た科目）は、グラフ上でトピックを共有するのは GMS-302 だけなのに、M1 は7件、M2 は2件の科目を「関連する」「親和性が高い」として足した。コードは DB に実在するので unverified には出ないが、科目間の関係はグラフに無く、LLM の推測になっている。
- 副次の「引用漏れ」に出た q14 の S0・S1 は、聞き返しの選択肢（golden の alternatives と同じ GMS-301・GMS-401）を本文に書いたもので、候補の提示ではない。
