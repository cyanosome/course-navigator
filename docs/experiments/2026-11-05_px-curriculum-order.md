## 7. 指標の定義

### PX-1

| 指標 | 定義と式 |
|---|---|
| 向きの正答率 | 正解数 ÷ 有効な項目数。正解は、到達可能性で先になる科目を選ぶこと |
| Wilson の 95% 区間 | (p + z²/2n ± z√(p(1−p)/n + z²/4n²)) / (1 + z²/n)、z = 1.95996 |
| McNemar（正確検定、両側） | p = min(1, 2·Σ_{k≤min(b,c)} C(b+c,k)/2^{b+c})。b・c は、片方の条件だけで正解した項目の数 |
| 検出の指標 | balanced accuracy = (TP/(TP+FN) + TN/(TN+FP))/2。MCC = (TP·TN − FP·FN)/√((TP+FP)(TP+FN)(TN+FP)(TN+FN))。適合率 = TP/(TP+FP)。再現率 = TP/(TP+FN) |
| 反対称の矛盾率 | 矛盾した鏡像の組 ÷ 2項目とも有効な組。矛盾とは、2つの提示で、先とした科目が違うこと |
| 三つ組の循環率 | 3つの答えが循環した組 ÷ 3項目とも有効な組 |
| κ | (po − pe)/(1 − pe)。O は正誤、D は答えを符号にする |
| 無効率 | 無効な項目 ÷ 120 |

### PX-2（Heileman et al. 2018, arXiv:1811.09676 の原典で式を確かめた）

| 指標 | 式 |
|---|---|
| blocking factor | b(v) = Σ_u I(v⇝u)（式7・8）。b(G) = Σ b(v)（式9） |
| delay factor | d(v) = v を通る最長路の頂点の数（式5）。d(G) = Σ d(v)（式6） |
| structural complexity | h(G) = d(G) + b(G)（式14） |
| 幅 | Dilworth の定理で求めた厳密値。最大反鎖と鎖による被覆で確かめた |
| 比較可能な割合 | 順序の付く非順序対 ÷ C(n,2) |

### 計算の例

- Gemini C1 の1回目（向き）: 117/120 = 0.975。Wilson の区間は [0.929, 0.991]
- Sonnet C0 の1回目（鏡像）: 組 M20 で、「A=基礎からの情報処理 / B=基礎分析化学」には A と答え、「A=基礎分析化学 / B=基礎からの情報処理」にも A と答えた。どちらも先に示した科目を先としたので矛盾。この回の矛盾は 2/30 = 0.067、2回目は 5/30 = 0.167 で、平均は 0.117
- Gemini C1 の1回目（検出）: TP 10・FP 1・TN 59・FN 50。balanced accuracy = (0.167 + 0.983)/2 = 0.575。MCC = (590 − 50)/√(11·60·60·109) = 0.260。適合率 = 10/11 = 0.909
- PX-2: 共通教養グループ（DP 抜き）は、到達できるグループが 11 なので b = 11。通る最長路の頂点は 6 なので d = 6

### 8.1 PX-2

| グラフ | ノード | エッジ | 推移簡約後 | 最長路（辺/頂点） | 幅 | 順序の付く対/全対 | b(G) | d(G) | h(G) |
|---|---|---|---|---|---|---|---|---|---|
| グループ DAG（DP 込み） | 21 | 25 | 25 | 6/7 | 7 | 108/210 = 0.514 | 108 | 131 | 239 |

- 列の意味: 推移簡約後は、推移律で導ける辺を除いた後の辺の数（どのグラフでも減らなかった）。幅は、互いに順序の付かない頂点の最大の数。b・d・h は、第7節の値をグラフ全体で合計したもの
- 最長路の例: 共通教養 → 1年 化学工学系 → 2年 ユニットオペレーション系 → 3年 応用化学工学系 → 特別研究Ⅰ → 特別研究Ⅱ

- 始点と終点（DP 抜き）: 始点は共通教養・フレッシュマンゼミナール・基礎化学英語・法規の 4、終点は特別研究Ⅱ・情報処理演習の 2
- 科目ごとの blocking factor の最大は、共通教養の 6 科目の 51
- 異なるグループの対に限ると、順序が付くのは 950/2234 = 0.425
- 科目 DAG は、グループの辺を所属科目の全組に引き継いで作った。そのため b が実際の前提関係より大きく出る（第11節）

## 10. 考察

### 言えること
- 順序: 公式の系統図の順序は、配当年次の規則で 97.5% 再現できる。シラバスには年次が載っているので、「先後」についてグラフが LLM＋シラバスに足せる情報は小さい。LLM はシラバス本文があれば 0.92〜0.97 だった（H1 不支持）。LLM の誤りは、ほとんどが年次の規則から外れたところで起きた（例: 図学・基礎分析化学を「より基礎」とみなす）。年次を与えると 0.96〜0.99 に上がるが、上がり幅は 0.05 に届かない（H5 不支持）。年次の規則がほぼ正解なので、上がる余地も小さい
- 関係の有無: グラフが「ある」とする関係の多くを、LLM は認めない（再現率 0.13〜0.54）。グラフと LLM の関係の集合は大きく違う。ただし年次差だけの規則でも MCC は 0.23 で LLM と同程度。この差が「LLM の知らない公式の情報」なのか、「グループの矢印を科目に引き継いだことで生じた粗さ」なのかは、この実験では分けられない
- 一貫性: 名前だけの Sonnet は、同じ対を逆の順で聞くと答えが変わることがある（12%）。グラフは定義上、矛盾しない。接地の利点として使える論点だが、Gemini では 0 で、モデルに依存する

### 言えないこと
- 「LLM だけでは足りない」ことの強い証拠は、向き課題からは得られなかった。新規性の根拠を「順序の再現」に置くのは弱い
- 関係の有無（D）を根拠にするには、科目単位の前提関係として妥当な正解が要る（履修要件や教員の判断など）

## 11. 限界

- 規模: 個人の予備実験で、1学科・1年度、各課題 120 項目、2モデル × 2回
- Sonnet の欠け: Sonnet の D は C2 の2回目が欠け、C1 の2回目は 100 項目
- 正解の作り方: 正解は、グループ間の矢印を所属科目の全組に引き継いだ到達可能性。系統図の線は、科目間の前提を意味するとは限らない。線が無いことは「無関係」と同じではない（構成概念の限界）。所属表はリポの手書きの表（PDF の座標で照合済み）
- 年次との重なり: 系統図は年次の段で描かれている。そのため O の正解は年次と強く重なり、「グラフの知識」と「年次の知識」を区別できない
- 科目の扱い: 2026 年度の一覧に無い3科目は外した。分割科目は講義を代表にした。複数クラスの科目は、syllabus_id が最小のクラスの文面を使った
- 生成の条件: 温度などは不明。agy は途中で自動更新された。LLM が関西大学の公開カリキュラムを学習している可能性は測れない
- 標本: D の正例の割合は設計上 0.5 で、母集団の 0.45 と少し違う
- プロンプト: JSON の例の答えが A・B の順なので、位置の誘導がありうる。ただし「A」と答えた数は 59〜68/120 で、大きな偏りは無い
- 副作用: この実験で、本人の agy の Claude Sonnet 5.5 の個人枠を使い切った（Sonnet の入力 約 103 万トークン・成功 66 回。回復は 2026-11-11 11時ごろ JST）。agy の Sonnet を使う他の作業もそれまで止まる。従量課金は起きていない。設計の段階で枠を見積もっていなかった
